# Brand marks

These five SVGs are vendored, unmodified from Simple Icons 15.15.0:
https://cdn.jsdelivr.net/npm/simple-icons@15.15.0/icons/

Simple Icons is a community-maintained collection distributed under CC0.
The marks remain trademarks of their respective owners. These files are not
custom illustrations or AI-generated approximations.

Upstream source references from `data/simple-icons.json` in that version:

- Instagram: https://about.meta.com/brand/resources/instagram
- Facebook: https://about.meta.com/brand/resources/facebook/logo
- Apple Music: https://www.apple.com/itunes/marketing-on-music/identity-guidelines.html#apple-music-icon
- Spotify: https://developer.spotify.com/documentation/general/design-and-branding/#using-our-logo
- YouTube: https://www.youtube.com/howyoutubeworks/resources/brand-resources/#logos-icons-and-colors

`BrandIcon` presents the black SVGs in monochrome white on the site's dark
background. Link text provides accessible names; the marks are decorative.
Keep this directory as SVG: converting vector brand marks to WebP would make
them less crisp and is unnecessary for these small files.
